## The Local/Cloud Split
By running a hybrid architecture on local silicon (Node1 with Ryzen AI 9 and RTX 5080), we achieve complete execution sovereignty without sacrificing high-level reasoning power.
- **The Gatekeeper (Local Gemma 12B):** Zero-cost, zero-latency forensic inspection. Polices code diffs, blocks test-fixture tampering, and drives the automated redemption retry loop locally.
- **The Architect (Cloud Gemini):** Heavy-lift conceptual synthesis, system topology mapping, and complex protocol design.

By keeping the verification layer anchored to immutable SHA-256 hashes on local hardware, we eliminate the honor system in agentic coding and establish a true zero-trust foundation for production automation.
